## 1. How the website is built (do not fight this)

Two shells, one source:

- **app-preview/** — the authoring shell. `app-preview/index.html` is ONE module: `route()` → `view.innerHTML`
  → `wire(sub)` → `enhanceStudyFlow(sub)`. Data: `app-preview/data/states.json` + per-state exports,
  `audio/<xx>/audio-manifest.json` (Utah: `audio/audio-manifest.json` at the root, pilot layout),
  `video/<xx>/video-manifest.json` (only ND today). This shell is the honest builder view and the hackathon's
  "how it is built" visualizer: its builder wording stays. Served by `node tools/preview/serve.mjs 4310`.
- **store/public/app/** — the customer copy, GENERATED by `node tools/preview/sync-store.mjs` from app-preview
  plus the patch layer in **store/learner-assets/** (`customer-ui.mjs` rewrites customer wording, `hub-ui.mjs`
  the module hub, `gate.js` the entitlement gate and funnel events, `learner.css` the look, `signs/` the
  MUTCD art, `visuals/` Sol's images). Never edit store/public/app by hand: edit the source, re-sync.
- **store/** — Next 15 wrapper (landing, /states/<slug>, sign-in, purchase, support, privacy, /api/*).
  Local mode: `node store/scripts/local-dev.mjs` → http://127.0.0.1:4320 with `STORE_LOCAL_MODE=1`
  (no Clerk, no Stripe; "Sign in as test learner", "Simulate purchase", "Simulate refund"). Clerk, Stripe and
  Vercel come LAST, after the store is complete (founder rule). Do not add keys, do not deploy.

Frame code that both shells share (lesson reader, step bar, video player) lives in `app-preview/index.html`
after `wire(sub)`; the hook is `enhanceStudyFlow(sub)`. Customer WORDING lives in `customer-ui.mjs`.
`sync-store.mjs` patches exact source strings in index.html (`  wire(sub);`, the dispatch lines, the
markDone lesson line, the `function stopAudio() {` … `let D = null;` span). **Never change those anchor
strings.** Run `node tools/preview/sync-store.mjs --check` after any index.html edit.

What is already in the frame (verified in the browser, both harnesses PASS, commits 3ce998599 → 57fe29a1d):
- Lesson page = **reading session**: book pages built from the unit data (slide pages, Key rules, Worked
  example, Common trap, Remember it, Quick check), Previous/Next, progress line, page count, one
