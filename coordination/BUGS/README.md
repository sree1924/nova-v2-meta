# BUGS — sweep queue (hackathon lane)

Founder order 2026-11-01: "keep an eye and write bugs in a separate folder for later sweep." Nothing here is fixed
when logged; each file is one bug, fixed only in the sweep (or sooner on the founder's word). Fable owns the folder;
Argon may add files (prefix `A-`) and must not close one.

Format: `BUG-NNN-<slug>.md` with `Status`, `Severity` (P0 blocks launch / P1 learner-visible wrong / P2 cosmetic-doc),
`Lane` (whose code), `Found`, `Where` (file:line or path), `What`, `Proof`, `Fix sketch`, `Closed` (date + how).
`INDEX.md` is the one-line-per-bug ledger.
