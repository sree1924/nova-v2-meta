## A — Exam authority for the Connecticut Class D knowledge test

Issuer: the Connecticut Department of Motor Vehicles issues driver licenses and publishes the Connecticut Driver’s Manual [A03].
Edition: the imprint page prints the edition line “Revised March 2023” [A03]; no effective date is printed, so the effective date stays unconfirmed (verify — sec02-A-EFFECTIVE-DATE).
Exam path: a first time applicant passes a vision test and a 25-question knowledge test to earn a learner permit [A07], then a road test for the license [A09].
Scoring: the knowledge test spans 25 questions with 20 correct answers needed to pass [A07]; the manual states no time limit, which stays unknown (verify — sec02-A-TIME-LIMIT).
Question format: beyond samples on the DMV mobile app, the manual does not describe the item format of the knowledge test (verify — sec02-A-FORMAT).
