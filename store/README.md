# PassLearnersPermit store (passlearnerspermit.com)

Production wrapper around the multi-state learner shell in `../app-preview/`.
Next.js 15.5.19 · @clerk/nextjs 7.5.7 · stripe 17.7.0 (same stack as the Nova fleet).
**PassLearnersPermit by DataPig LLC.**

Product (founder, 2026-10-28): **one state for one year, $9.99**, one-time Stripe Checkout, no
bundles, no subscriptions. Free: state picker + chapter 1 of every state (lesson, flashcards,
quiz) + Utah's chapter-1 narration. Everything else is behind the paywall.

## Layout

| Path | What |
|---|---|
| `public/app/` | Mirror of the shell, made by `../tools/preview/sync-store.mjs`. **Never hand-edit** — re-run the sync. |
| `public/app/gate.js` | The only hand-authored file in the mirror: paywall + quarantine gate (`window.NovaGate`). |
| `src/generated/` | `free-paths.json` (middleware allowlist), `catalog.json` (landing pages) — generated by the sync. |
| `src/middleware.ts` | Clerk on pages/API; `/app` → `/app/`; paid `/app/**` files need the signed `plp_ent` cookie. |
| `src/app/api/checkout` | `GET ?state=TX` → 401 signed out, else a $9.99 Checkout Session (metadata `{state, userId, brand, product}`) → 303 to Stripe. |
| `src/app/api/checkout/confirm` | `POST {sessionId}` — buyer return path; verified, idempotent grant. |
| `src/app/api/stripe/webhook` | Signed webhook: grant on `checkout.session.completed` / `async_payment_succeeded`; revoke on `charge.refunded`. |
| `src/app/api/me` | `GET` → `{signedIn, entitlements}`; refreshes/clears the `plp_ent` cookie. |
| `src/lib/fulfillPurchase.ts` | Writes Clerk `publicMetadata.entitlements = {"TX": "<ISO expiry, purchase + 1 year>"}` + `purchases.TX = {session, at, expires}`. |
| `/`, `/states/<slug>` | Indexable picker + 23 state landing pages; `sitemap.xml`, `robots.txt`. |
| `/support`, `/refunds`, `/terms`, `/privacy` | Policy pages. |

## Run

```sh
cd D:/nova/fb-ai-hackathon/store
npm install
npm run sync            # mirror app-preview -> public/app (+ generated inputs); incremental, re-runnable
npm run dev             # http://localhost:4320  (founder keeps 3000)
npm run build           # prebuild checks the mirror exists
npm run verify:shell    # harness against the store copy (gate + quarantine checks included)
node ../tools/preview/verify-learner.cjs   # harness against app-preview (must stay ALL PASS)
```

`.env.local` holds local keys (never commit it; `.gitignore` covers it). The one created on
2026-10-28 holds **placeholders only**: pages, `/api/me` and the 401 paths work, but sign-in
and checkout need a real Clerk **development** instance and Stripe **test** keys. With
placeholder Clerk keys a real browser hitting `/app/` is bounced to Clerk's dev handshake and
fails; curl and the harness are unaffected.

Local test-mode purchase (after real dev/test keys are in `.env.local`):
`stripe listen --forward-to localhost:4320/api/stripe/webhook` (put its `whsec_` in
`STRIPE_WEBHOOK_SECRET`), sign in, open `/states/texas` → Buy → card `4242 4242 4242 4242`.

## How the gate works

1. `gate.js` loads before the shell and fetches `/api/me` + `quarantine-index.json`.
2. Patched `loadReal` (STORE PATCH, applied by the sync to the copy only) fetches chapter 1 of
   every state, and other chapters only with an unexpired entitlement for that state.
3. Patched `routeState`: chapters 2+ (chapter, module hub, lesson, cards, quiz, practice form)
   render the buy panel ($9.99, what you get, "Narration audio: Utah only for now", 7-day
   refund line) unless `entitlements[state]` is in the future.
4. Server side the same rule: `middleware.ts` serves the generated free allowlist to anyone;
   any other `/app/**` file needs the HMAC-signed `plp_ent` cookie (12 h, `Path=/app`,
   HttpOnly) that `/api/me` mints from Clerk `publicMetadata`.
   The shell carries no Clerk JS, so the cookie, not the 60-second Clerk session token,
   authorizes its data and audio fetches.
5. Quarantine: card ids listed in `app-preview/data/<xx>/quarantine.json` are hidden from
   decks, card scripts and recaps at render time (files untouched); the deck shows
   "N cards held back for a wording fix".

## Known limits

- Narration audio exists for Utah only. Every other state is text, and the copy says so everywhere.
- Edition dates: VA and NY show "(verify)". No edition date was found in their exports.
  CO, NC, MD, IN, CA and FL dates are quoted from their dossiers (`src/lib/editions.ts`).
- Registry quirk: `app-preview/data/states.json` names Connecticut `"CT"`. Store pages use
  the USPS name table; the shell itself shows "CT".
- The entitlement cookie lasts up to 12 h, so a refund revokes `/app/**` file access within 12 h.
  `/api/me` and the shell's buy panel see the revocation on the next page load.
